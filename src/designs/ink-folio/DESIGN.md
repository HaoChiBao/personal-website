# Ink Folio

## Status
`ready`

## Visual identity
Dark single-column portfolio: black ground, serif display (Tiempos Fine) + Aeonik body, banner + overlapping profile strip, dashed section rules, rounded project cards with media headers, pill contact/tech chips. Inspired by contemporary design-engineer personal sites — adapted for James Yang.

## Goals
- First viewport: banner + name/role/location as one composition
- Clear section rhythm: About → Contact → Projects → Stack → Activity → CTA
- Motion: soft fade-up on load, subtle hover on cards/pills

## Color
- Background: `#050505`
- Surface / cards: `#0e0e0e`
- Border: `rgba(255,255,255,0.08)`
- Text: `#f5f5f5`
- Muted: `#8a8a8a`
- Live accent: `#3dd68c`
- CTA fill: `#f5f5f5` on black label
