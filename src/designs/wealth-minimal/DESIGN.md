# Wealth Minimal

## Status
`ready`

## Visual identity
Personal site inspired by Wealthsimple: warm off-white surfaces, near-black type, signature lime accent, pill CTAs, friendly hierarchy. Still simple — no dense dashboards or card clutter.

## Goals
- Approachable fintech-clean, not sterile Apple chrome
- Name-forward hero with one clear CTA
- Quiet project list; one job per section

## Color
- Background: `#FAF8F5`
- Wash / bands: `#F1EDE6`
- Text: `#1C1917`
- Secondary: `#6B6560`
- Accent (lime): `#C8F135`
- Accent hover: `#B8E62A`
- Hairline: `rgba(28, 25, 23, 0.10)`

## Type
Prefer loaded site fonts (`Aeonik`) with system fallbacks. Large friendly headlines, readable 17–19px body.

## Components
- Pill primary button: lime fill, black label
- Text links: underline on hover, secondary or accent
- Soft section washes; no heavy shadows
- Project rows with hairline dividers

## Switching
`?design=wealth-minimal` or Dev switcher → **Wealth Minimal**
